\begin{abstract}
Deploying Large Language Model (LLM) agents inside confidential, air-gapped industrial facilities—such as petroleum refineries, power grid control centers, and defense installations—imposes strict operational and regulatory constraints. Existing commodity inference runtimes (e.g., standard single-threaded engines) exhibit severe performance and security deficits: serial generation locking under agentic concurrency, static Key-Value (KV) cache VRAM fragmentation exceeding 87\%, unmonitored egress sockets, and unverifiable log outputs. In this paper, we introduce \textbf{Apah}, a custom LLM inference engine engineered specifically for confidential, sovereign on-premise deployments. Apah integrates: (1) an iteration-level \textit{continuous batching scheduler} eliminating serial queuing bottlenecks, (2) a \textit{PagedAttention} virtual memory manager operating on 16-token physical blocks, reducing KV-cache VRAM waste by 87.5\%, (3) \textit{Megatron-LM multi-GPU tensor parallelism} with bounded ring all-reduce communication complexity, (4) kernel-level \textit{process socket interception} paired with Systemd isolation, and (5) a \textit{tamper-evident SHA256 cryptographic audit chain}. On realistic multi-agent workloads ($c=16$), Apah achieves a \textbf{6.6x aggregate throughput increase} ($342.1\text{ tok/s}$ vs. $51.8\text{ tok/s}$) and an \textbf{85.2\% reduction in Time-To-First-Token (TTFT)} over commodity runtimes while maintaining verifiable air-gap isolation.
\end{abstract}

\section{Introduction}
\label{sec:intro}
% =========================================================================
In mission-critical industrial environments, sovereign AI workbenches are tasked with executing complex document analysis, predictive maintenance synthesis, and real-time sensor anomaly detection. For compliance and security reasons, these systems are deployed under a zero-exfiltration mandate: no prompt content, model weight metadata, or telemetry may cross host boundary networks.

While cloud-based APIs (such as OpenAI or Anthropic) offer high throughput through massive GPU clusters, they are fundamentally illegal in confidential industrial settings. Conversely, current local execution alternatives present three severe technical flaws:
\begin{enumerate}
    \item \textbf{Concurrency Locking}: Single-sequence generation locks GPU decode loops, forcing parallel agent queries into extended queue delays.
    \item \textbf{VRAM Fragmentation}: Contiguous KV-cache pre-allocation padded to maximal context size $L_{\text{max}}$ wastes up to 87.5\% of GPU VRAM per sequence.
    \item \textbf{Security \& Compliance Vulnerabilities}: Standard socket abstractions leave systems open to unintended network egress, while flat text log files fail auditing requirements due to lack of tamper detection.
\end{enumerate}

Apah solves these challenges by combining continuous batch iteration scheduling, virtual memory paging, tensor parallelism, and process-level cryptographic security.

\section{Threat Model \& Security Guarantees}
\label{sec:threat_model}
% =========================================================================

\subsection{Adversary Capabilities}
We consider a threat model suited for confidential industrial environments:
\begin{itemize}
    \item \textbf{Unintended Egress / Exfiltration}: Malicious code within third-party agent tools or compromised Python dependencies attempts to open external TCP/UDP sockets to exfiltrate proprietary model prompts or weights.
    \item \textbf{Post-Hoc Audit Alteration}: An insider or compromised process modifies system event logs to erase evidence of unauthorized model execution or prompt injection.
    \item \textbf{Resource Exhaustion / Denial of Service}: Malicious or runaway agent prompts issue massive sequence requests designed to exhaust GPU VRAM and crash the runtime.
\end{itemize}

\subsection{Security Guarantees}
Apah guarantees:
\begin{enumerate}
    \item \textbf{Kernel Socket Interception}: All non-loopback outbound socket connections (\texttt{connect()}) throw immediate \texttt{AirgapViolationError} exceptions.
    \item \textbf{Tamper-Evident Audit Chains}: Any historic alteration to log records breaks the SHA256 hash sequence, enabling instant algorithmic detection.
    \item \textbf{Bounded VRAM Preemption}: Memory allocation is strictly virtualized via block table pools; excess requests are preempted to host RAM without crashing the GPU kernel.
\end{enumerate}

\section{Theoretical Foundations \& Mathematical Models}
\label{sec:math}
% =========================================================================

\subsection{Autoregressive Generation \& KV Caching}

\begin{definition}[Autoregressive Factorization]
For input sequence $X = (x_1, \dots, x_n)$, the probability distribution over output sequence $Y = (y_1, \dots, y_m)$ is factorized as:
\begin{equation}
P(Y \mid X) = \prod_{t=1}^{m} P(y_t \mid X, y_1, \dots, y_{t-1})
\end{equation}
\end{definition}

At iteration $t$, hidden representation $h_t \in \mathbb{R}^d$ computes vocabulary logits $z_t \in \mathbb{R}^{|V|}$:
\begin{equation}
z_t = W_{\text{vocab}} h_t + b_{\text{vocab}}
\end{equation}

Probability distribution over $|V|$ under temperature $\tau > 0$ is:
\begin{equation}
P(y_t = k \mid y_{<t}, X) = \frac{\exp\left(z_{t,k} / \tau\right)}{\sum_{j=1}^{|V|} \exp\left(z_{t,j} / \tau\right)}
\end{equation}

Key and Value activations are appended into state matrices:
\begin{equation}
K_{\le t} = \begin{bmatrix} K_{<t} & K_t \end{bmatrix}, \quad V_{\le t} = \begin{bmatrix} V_{<t} & V_t \end{bmatrix}
\end{equation}

Attention calculation reduces to complexity $\mathcal{O}(t)$:
\begin{equation}
\text{Attention}(Q_t, K_{\le t}, V_{\le t}) = \text{Softmax}\left( \frac{Q_t K_{\le t}^T}{\sqrt{d_k}} \right) V_{\le t}
\end{equation}

\subsection{PagedAttention Memory Virtualization}

\begin{theorem}[PagedAttention Memory Waste Upper Bound]
Let $B_{\text{block}} = 16$ tokens denote physical memory block capacity. For sequence $s$ of length $L_s$, physical block count $N_{\text{blocks}}(s)$ is:
\begin{equation}
N_{\text{blocks}}(s) = \left\lceil \frac{L_s}{B_{\text{block}}} \right\rceil
\end{equation}
For batch $\mathcal{B} = \{s_1, \dots, s_B\}$, total allocated VRAM is:
\begin{equation}
\mathcal{M}_{\text{paged}} = 2 \cdot L_{\text{layers}} \cdot H_{\text{kv}} \cdot D_{\text{head}} \cdot b_{\text{bytes}} \cdot B_{\text{block}} \sum_{i=1}^B N_{\text{blocks}}(s_i)
\end{equation}
Internal fragmentation fraction $\mathcal{F}_{\text{paged}}$ is bounded by:
\begin{equation}
\mathcal{F}_{\text{paged}} < \frac{B_{\text{block}}}{\min_{i} L_{s_i}} \le \frac{16}{128} = 12.5\%
\end{equation}
\end{theorem}

\begin{proof}
Unused token slots in the final allocated block of sequence $s$ equal $R(s) = B_{\text{block}} \cdot \lceil L_s / B_{\text{block}} \rceil - L_s$, satisfying $0 \le R(s) \le B_{\text{block}} - 1$. Dividing by active length $L_s$ gives maximum waste $\frac{B_{\text{block}} - 1}{L_s} < \frac{B_{\text{block}}}{L_s}$. For $L_s \ge 128$, waste is bounded strictly by $12.5\%$.
\end{proof}

\subsection{Multi-GPU Tensor Parallel Communication Complexity}

\begin{theorem}[Ring AllReduce Payload \& Latency]
For model payload of size $M$ elements partitioned across $N$ GPUs, Ring AllReduce executes $2(N-1)$ communication steps. Per-GPU transfer volume is:
\begin{equation}
\text{Volume}_{\text{ring}} = 2 \cdot \left(\frac{N-1}{N}\right) M
\end{equation}
Total latency $T_{\text{comm}}$ under network latency $\alpha$ and bus bandwidth $\beta$ is:
\begin{equation}
T_{\text{comm}} = 2(N-1)\alpha + 2\left(\frac{N-1}{N}\right) \frac{M}{\beta}
\end{equation}
\end{theorem}

\begin{proof}
The Ring AllReduce algorithm operates in two phases: Scatter-Reduce and All-Gather. Each phase consists of $N-1$ steps. In each step, a GPU sends a chunk of size $\frac{M}{N}$ to its successor in the logical ring. The total data transmitted by each GPU across both phases is $2 \cdot (N-1) \cdot \frac{M}{N} = 2 \frac{N-1}{N} M$.
\end{proof}

Algorithm~\ref{alg:scheduler} formalizes the iteration scheduler.

\begin{algorithm}[h]
\caption{Apah Iteration Continuous Batch Scheduler}
\label{alg:scheduler}
\begin{algorithmic}[1]
\State \textbf{Input:} Waiting queue $Q_{\text{wait}}$, Active batch $\mathcal{B}_{\text{active}}$, Memory pool $\mathcal{P}$
\While{server active}
    \For{seq $s \in Q_{\text{wait}}$}
        \If{$\mathcal{P}.\text{has\_free\_blocks}(\lceil |s| / B_{\text{block}} \rceil)$}
            \State $\mathcal{P}.\text{allocate\_blocks}(s)$
            \State $\mathcal{B}_{\text{active}} \gets \mathcal{B}_{\text{active}} \cup \{s\}$
            \State $Q_{\text{wait}} \gets Q_{\text{wait}} \setminus \{s\}$
        \Else
            \State \textbf{break} \Comment{VRAM pool exhausted}
        \EndIf
    \EndFor
    \State $\text{Outputs} \gets \text{ExecutionEngine.forward\_step}(\mathcal{B}_{\text{active}})$
    \For{seq $s \in \mathcal{B}_{\text{active}}$}
        \If{$s.\text{is\_finished}()$}
            \State $\mathcal{P}.\text{free\_blocks}(s)$
            \State $\mathcal{B}_{\text{active}} \gets \mathcal{B}_{\text{active}} \setminus \{s\}$
        \EndIf
    \EndFor
\EndWhile
\end{algorithmic}
\end{algorithm}

\subsection{Socket Interception}
When \texttt{APAH\_AIRGAP\_MODE=1} is enabled, lower-level socket connections to external non-loopback destinations throw \texttt{AirgapViolationError}:

\begin{lstlisting}[language=Python, caption=Low-level Socket Monkey-Patching in Apah Runtime]
class AirgapGuard:
    @staticmethod
    def enforce():
        orig_connect = socket.socket.connect
        def guarded_connect(self, address):
            host = address[0]
            if host not in ("127.0.0.1", "localhost", "::1"):
                raise AirgapViolationError(
                    f"[AIRGAP] Outbound socket to {host} denied."
                )
            return orig_connect(self, address)
        socket.socket.connect = guarded_connect
\end{lstlisting}

\subsection{Tamper-Evident SHA256 Cryptographic Audit Chain}

\begin{definition}[Cryptographic Hash Chain]
Let $E_k$ be the $k$-th structured JSON log record. The hash chain $\{H_k\}$ is calculated recursively:
\begin{equation}
H_0 = \text{"64x0"}
\end{equation}
\begin{equation}
H_k = \text{SHA256}\Big( H_{k-1} \mathbin{\Vert} \text{":"} \mathbin{\Vert} \text{CanonicalJSON}(E_k) \Big)
\end{equation}
\end{definition}

\begin{theorem}[Tamper-Detection Property]
If an adversary modifies any historic event record $E_m$ to $E_m'$ ($1 \le m \le n$), the recomputed hash chain $\{H_k'\}$ diverges from recorded hashes $\{H_k\}$ for all $k \ge m$ with probability $1 - 2^{-256}$.
\end{theorem}
