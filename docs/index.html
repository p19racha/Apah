the_problem

throughput_ceiling

- Ollama: single-request serial lock causes concurrent agent queuing bottlenecks
- Traditional KV-Cache: contiguous padded VRAM allocation wastes up to 87.5% memory
+ Apah Engine: continuous batching scheduler handles concurrent generation in shared forward passes
+ PagedAttention: non-contiguous 16-token physical blocks eliminate memory fragmentation
architecture

execution_pipeline

Apah wraps custom CUDA kernels in a FastAPI server exposing OpenAI-compatible endpoints with process-level isolation:

  • API Layer: FastAPI server with OpenAI Chat Completions (/v1/chat/completions), Tool Calling, Vector Embeddings (/v1/embeddings), and Ollama compatibility shims.
  • Continuous Batching Scheduler: Iteration-level scheduling queue admitting new sequences between decode steps without waiting for full batch completion.
  • PagedAttention Engine: Demand-allocated physical memory block pool (BlockPool & BlockTable) managing Key-Value tensors without padding.
  • Tensor Parallel Engine: Megatron-LM style Column and Row parallel weight matrix partitioning across $N$ NVIDIA GPUs via NCCL AllReduce.
  • Process Isolation & Airgap Guard: Socket-level network interception (APAH_AIRGAP_MODE=1) and tamper-evident SHA256 cryptographic audit logging.

commands

cli_reference

Subcommand Description
apah serve Start the Apah inference server in the foreground (blocking).
apah run Run model inference (one-shot prompt or interactive chat REPL).
apah pull Pull model weights, version, compute checksums, and verify manifest integrity.
apah list List locally downloaded model manifests across all versions.
apah ps List models currently loaded in server GPU memory.
apah gpu Display real-time NVIDIA GPU hardware metrics (memory, utilization %, temperature).
apah stop Unload the currently loaded model from server GPU memory.
apah rm Remove a local model directory or specific version from ~/.apah/models/.
apah show Show detailed manifest, checksum verification summary, and live server status.
apah audit verify Verify SHA256 hash chain integrity of audit log files.
apah audit tail Pretty-print the last N audit log events in human-readable format.
