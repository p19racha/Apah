architecture

execution_pipeline

Apah combines custom CUDA kernels with a FastAPI server exposing OpenAI-compatible endpoints and process-level air-gap security:

  1. OpenAI FastAPI Server: Compatible shims for /v1/chat/completions, tool calling, embeddings, and Ollama client drop-in support.
  2. Continuous Batching Scheduler: Iteration-level sequence queue admitting prompts dynamically between decode iterations.
  3. PagedAttention BlockPool: Virtual memory manager allocating physical 16-token KV cache pages without memory fragmentation.
  4. Tensor Parallel Engine: NCCL AllReduce distributing Megatron-style Column/Row matrix projections across N NVIDIA GPUs.
  5. Air-Gap Hardening & Audit: Kernel socket interception blocking unauthorized egress with tamper-evident SHA256 audit log chains.

commands

cli_reference

apah serve Start the Apah inference server in the foreground (blocking).
apah run Run model inference (one-shot prompt or interactive chat REPL).
apah pull Pull model weights, version, compute checksums, and verify manifest integrity.
apah list List locally downloaded model manifests across all versions.
apah ps List models currently loaded in server GPU memory.
apah gpu Display real-time NVIDIA GPU hardware metrics (memory, utilization %, temperature).
apah stop Unload the currently loaded model from server GPU memory.
apah rm Remove a local model directory or specific version from ~/.apah/models/.
apah show Show detailed manifest, checksum verification summary, and live server status.
apah audit verify Verify SHA256 hash chain integrity of audit log files.

security_modes

airgap_levels

standard

Standard network sockets enabled. Best for development, local debugging, or non-sensitive staging environments.

[default]

airgap_enforced

Process-level socket creation intercepted and blocked. Zero outbound network egress allowed.

hardened_audit

Strict air-gap enforcement combined with SHA256 cryptographic tamper-evident audit logging for industrial compliance.
