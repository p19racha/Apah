// github pages & script hosting setup guide

Step-by-step instructions for hosting and verifying Apah one-line installer scripts on GitHub Pages.

back to main repository settings

gh_pages_setup

deployment_steps

  1. Open Repository Settings: Navigate to your GitHub repository at https://github.com/p19racha/Apah.
  2. Access Pages Tab: Click on the Settings tab in the top navigation bar, then select Pages under Code and automation.
  3. Configure Source Branch: Under Build and deployment, set Source to Deploy from a branch.
  4. Select Folder Directory: Select main branch and specify /docs as the root folder directory.
  5. Save & Publish: Click Save. GitHub Pages will build and deploy the landing page at https://p19racha.github.io/Apah/.

script_verification

plain_text_validation

Before running piped execution (curl ... | sh), verify that GitHub Pages serves install.sh as plain text:

~/apah $ curl -fsSL https://p19racha.github.io/Apah/install.sh | head -n 10

Expected raw output header:

EXPECTED HEADER install.sh 
+ #!/bin/sh
+ # Apah POSIX One-Line Installer for Linux and macOS
